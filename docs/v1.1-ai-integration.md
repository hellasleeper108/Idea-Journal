# v1.1 AI Integration Plan

Idea Journal v1.1 turns the app from a passive parking lot into an agent-ready
workspace for Claude Code and Codex.

## Claude Integration

- Add `/claude` command input inside each idea modal.
- Route `/claude expand`, `/claude scaffold`, and free-form commands through the
  FastAPI sidecar.
- Add Anthropic SDK support with `ANTHROPIC_API_KEY` and optional
  `ANTHROPIC_MODEL`.
- Keep a deterministic fallback response so local tests pass without API keys.
- Add `.claude/commands/` slash-command files for Claude Code.

## Codex Integration

- Expose `GET /ideas/active` so Codex can poll work currently in flight.
- Add first-class `/codex` commands inside each idea modal.
- Expose `POST /codex/scaffold` as the scaffold contract for Codex.
- Expose `POST /codex/plan` for implementation plans generated from a journal
  idea.
- Add `.codex/AGENTS.md` with the expected Codex workflow.
- Let Codex update completed planning details with `PATCH /ideas/{id}`.

## Sidecar Endpoints

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/ideas/active` | Agent polling for in-flight ideas |
| `POST` | `/claude/expand` | Expand and patch idea fields |
| `POST` | `/claude/scaffold` | Return scaffold brief for code agents |
| `POST` | `/claude/score` | Batch-score parked ideas older than cooldown |
| `POST` | `/claude/command` | Stream inline `/claude` responses to UI |
| `POST` | `/codex/expand` | Expand and patch idea fields for Codex handoff |
| `POST` | `/codex/scaffold` | Return Codex scaffold brief |
| `POST` | `/codex/plan` | Return Codex implementation plan |
| `POST` | `/codex/command` | Stream inline `/codex` responses to UI |

## Runtime

Set `ANTHROPIC_API_KEY` before starting the backend to enable live Claude
responses. Without the key, the sidecar returns stable local draft responses for
development and tests.
